# e-plantShopping

Paradise Nursery is a React-based online plant shopping application.

## Features

- Landing page with background image
- About Us section
- Product listing page
- Shopping cart functionality
- Add items to cart
- Remove items from cart
- Update product quantity
- Total amount calculation
- Redux state management

## Technologies Used

- React JS
- Redux Toolkit
- CSS
- JavaScript

## Project Structure

src/
├── App.jsx
├── App.css
├── AboutUs.jsx
├── ProductList.jsx
├── CartItem.jsx
└── CartSlice.jsx

## Installation

1. Clone the repository
2. Install dependencies using:

npm install

3. Start the project using:

npm start
